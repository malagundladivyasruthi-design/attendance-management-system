# Attendance Management System

A simple web-based attendance management system.

## Features

- Add students
- Mark students as Present
- Mark students as Absent
- Calculate attendance percentage
- Delete students
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Preview

The project allows users to manage student attendance and automatically calculate attendance percentages.
